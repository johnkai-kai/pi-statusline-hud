Three things to fix along the way

1. The username leaks. The repo row shows the last segment of the home directory — on Windows that is the account name. When cwd is home, the last segment is the account. Change it to show ~ for home and ~/subdir below it.
2. An empty motto leaves a stray separator. Found while previewing: once coloured, an empty string is no longer empty, so the current filter(Boolean) stops working. The fix is to filter before colouring.
3. 0 skills looks like the wrong path. Your pi has skills but they count as 0; check while implementing.

Technical notes

  • Colour uses truecolor ANSI ([38;2;R;G;Bm), the same mechanism as pi-statusline's ansiFg.
  • ANSI escapes inflate string length, so the current truncate(text, width) misjudges the width and breaks the layout. Every row must measure and truncate as plain text first, and colour last.
  • palettePreset goes from a dead key to a real one: tokyo-night (this page) and mono (no colour, for terminals without truecolor).
