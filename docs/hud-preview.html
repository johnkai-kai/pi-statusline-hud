三個順手要修的問題

1. 使用者名稱外洩。目前 repo 行會顯示家目錄的末段 —— 在 Windows 上那就是帳號名。cwd 是家目錄,取末段就變帳號。改為家目錄顯示 ~,家目錄底下顯示 ~/子目錄。
2. 空座右銘會留下多餘分隔線。預覽時實測到的:上色後空字串不再是空字串,現行的 filter(Boolean) 失效。修法是先過濾再上色。
3. 0 skills 疑似掃錯路徑。你的 pi 有 skills 卻數成 0,實作時一併查。

技術要點

  • 上色走 truecolor ANSI([38;2;R;G;Bm),與 pi-statusline 的 ansiFg 同機制。
  • ANSI 逸出碼會撐長字串,現行的 truncate(text, width) 會誤判寬度而破版。所以每一行必須「先以純文字算寬度與截斷,最後才上色」。
  • palettePreset 從死鍵變成真的能切:tokyo-night(本頁)與 mono(不上色,給不支援 truecolor 的終端)。
